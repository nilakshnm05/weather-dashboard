# Array Manipulation

## Useful Methods

- push() → Add to the end.
- pop() → Remove from the end.
- shift() → Remove the first element.
- unshift() → Add to the beginning.
- filter() → Create a new array based on a condition.
- some() → Check if any element matches.

---

## Why?

Arrays are commonly used to manage application state such as search history, carts, notifications, and recent activity.

## Revision

Choose the array method based on the behavior you want.
