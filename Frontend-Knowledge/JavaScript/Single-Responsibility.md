# Single Responsibility Principle (SRP)

## What is SRP?

A function should have one clear responsibility.

---

## Why?

- Easier to read
- Easier to test
- Easier to debug
- Easier to reuse

---

## Bad

One function validates input, updates UI, calls APIs, and saves data.

---

## Good

Split into smaller functions with one clear purpose.

---

## Interview Question

What is the Single Responsibility Principle?

---

## Revision (30 sec)

One function → One responsibility.
