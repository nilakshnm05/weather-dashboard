# DRY (Don't Repeat Yourself)

## What is DRY?

Avoid duplicating the same logic in multiple places.

---

## Why?

- Easier maintenance
- Fewer bugs
- Better readability
- One source of truth

---

## Bad

Same UI reset code copied into multiple functions.

---

## Good

Extract repeated logic into a reusable function.

---

## Interview Question

What does DRY mean?

---

## Revision

Write once.

Reuse many times.
