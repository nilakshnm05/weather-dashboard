# Error Handling

## What is Error Handling?

Handling unexpected situations without crashing the application.

---

## Why?

- Better user experience
- Easier debugging
- More reliable applications

---

## Good Practice

- Show friendly messages to users.
- Log actual errors using `console.error()`.

---

## Defensive Programming

Assume things can fail.

Write code that handles failure gracefully.

---

## Revision

Users need helpful messages.

Developers need detailed errors.
