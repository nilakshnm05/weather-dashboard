## Security Note

This project is built using Vanilla JavaScript.

The API keys are currently stored in the client-side code because the browser directly communicates with third-party APIs.

This approach is suitable for learning purposes but does not completely protect API keys.

Future improvements:

- Move configuration to environment variables after migrating to Vite.
- Proxy API requests through a backend server.
- Store sensitive keys securely on the server.
